# หมวดอนามัยแม่และเด็ก (mch-anc)

query สำหรับตัวชี้วัดกลุ่มอนามัยแม่และเด็ก งานฝากครรภ์ (ANC) และห้องคลอด

## query ที่มีในหมวดนี้

| query | ตัวชี้วัด | สถานะ |
|---|---|---|
| [maternal-anemia/](maternal-anemia/) | ภาวะโลหิตจางในหญิงตั้งครรภ์ที่มารับบริการฝากครรภ์ (maternal anemia) | draft |
| [preterm-birth/](preterm-birth/) | ร้อยละการคลอดก่อนกำหนด (preterm delivery rate) | draft |

## ยังขาดอะไรอีก

หมวดนี้ยังต้องการ query อีกหลายตัว เช่น ฝากครรภ์ครั้งแรกก่อน 12 สัปดาห์, ฝากครรภ์ครบ 5 ครั้งตามเกณฑ์, ทารกแรกเกิดน้ำหนักน้อยกว่า 2,500 กรัม

ถ้าโรงพยาบาลของคุณมี query เหล่านี้อยู่แล้ว ช่วยแบ่งปันได้ตามขั้นตอนใน [CONTRIBUTING.md](../../CONTRIBUTING.md) ดูรายการเต็มได้ที่ [docs/kpi-catalog.md](../../docs/kpi-catalog.md)
