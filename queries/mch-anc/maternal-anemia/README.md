# ภาวะโลหิตจางในหญิงตั้งครรภ์ที่มารับบริการฝากครรภ์ (ANC)

สถานะ: **draft** | HIS: HOSxP (MySQL/MariaDB) | ไฟล์ query: [hosxp.sql](hosxp.sql)

> query นี้ใช้เพื่อตรวจสอบและเตรียมข้อมูลภายในโรงพยาบาลเท่านั้น ไม่ใช่ค่าทางการ
> ค่าทางการอ้างอิงจากระบบ HDC ของกระทรวง (https://hdcservice.moph.go.th)

## ชื่อตัวชี้วัดและความหมาย

ร้อยละของหญิงตั้งครรภ์ที่มารับบริการฝากครรภ์ (ANC) แล้วพบภาวะโลหิตจาง
วัดจากผลตรวจ haemoglobin (Hb) ครั้งแรกในช่วงเวลาที่กำหนด

- **ตัวตั้ง (numerator)** : จำนวนหญิงตั้งครรภ์ที่ผล Hb ครั้งแรกในช่วงเวลา ต่ำกว่าเกณฑ์ที่กำหนด
- **ตัวหาร (denominator)** : จำนวนหญิงตั้งครรภ์ที่มารับบริการ ANC ในช่วงเวลา และมีผล Hb แบบตัวเลขอย่างน้อย 1 ครั้ง

query ยังรายงานเพิ่มอีก 2 ค่าเพื่อใช้ตรวจสอบคุณภาพข้อมูล:
จำนวนหญิงตั้งครรภ์ทั้งหมดในช่วงเวลา และจำนวนที่ไม่มีผล Hb เลย
(ถ้าจำนวนที่ไม่มีผล Hb สูงผิดปกติ มักแปลว่ารหัส lab ที่ตั้งไว้ยังไม่ครบ หรือผล lab ถูกบันทึกเป็นข้อความ)

## นิยามและแหล่งอ้างอิง

เกณฑ์วินิจฉัยภาวะโลหิตจางในหญิงตั้งครรภ์:

- WHO 2011 กำหนดภาวะโลหิตจางในหญิงตั้งครรภ์ที่ Hb ต่ำกว่า 11.0 g/dL
  อ้างอิง: WHO. Haemoglobin concentrations for the diagnosis of anaemia and assessment of severity. Vitamin and Mineral Nutrition Information System. Geneva: World Health Organization; 2011 (WHO/NMH/NHD/MNM/11.1)
- WHO 2024 ปรับเกณฑ์แยกตามไตรมาส: ต่ำกว่า 11.0 g/dL ในไตรมาสที่ 1 และ 3 และต่ำกว่า 10.5 g/dL ในไตรมาสที่ 2
  อ้างอิง: WHO. Guideline on haemoglobin cutoffs to define anaemia in individuals and populations. Geneva: World Health Organization; 2024
- หน้างานฝากครรภ์ในไทยจำนวนมากคัดกรองด้วย hematocrit (Hct) ด้วย query นี้ใช้ผล Hb อย่างเดียว
  ถ้าต้องการใช้เกณฑ์ Hct ให้ยึดค่าจาก template ตัวชี้วัดของปีงบประมาณปัจจุบันใน HDC แล้วปรับ query เอง

query นี้ใช้เกณฑ์เดียวคือ Hb ต่ำกว่า `@hb_cutoff` (ค่าเริ่มต้น 11.0 g/dL ตาม WHO 2011)
เพราะข้อมูลอายุครรภ์รายไตรมาสในแต่ละโรงพยาบาลเก็บไม่เหมือนกัน จึงยังไม่แยกเกณฑ์ตามไตรมาส

นิยามทางการของตัวชี้วัดใน HDC อาจต่างจากนี้ในรายละเอียด และเปลี่ยนได้ทุกปีงบประมาณ
ก่อนใช้รายงานทางการ ให้ตรวจสอบนิยามและค่าเป้าหมายจาก template ตัวชี้วัดของปีงบประมาณปัจจุบันใน
HDC (https://hdcservice.moph.go.th) หรือ Health KPI กระทรวงสาธารณสุข (https://healthkpi.moph.go.th)

## แนวคิดของ query

query แบ่งเป็น 3 ขั้น (เขียนด้วย derived table รองรับ MySQL 5.x ไม่ใช้ CTE):

1. **หา cohort หญิงตั้งครรภ์ (ตัวหารตั้งต้น)**
   ดึง hn ที่มี visit ในช่วงวันที่ (`ovst.vstdate`) และมีการลงรหัสวินิจฉัยกลุ่มการดูแลการตั้งครรภ์
   คือ ICD-10 (WHO) รหัส Z34 (supervision of normal pregnancy) หรือ Z35 (supervision of high-risk pregnancy)
   จาก `ovstdiag` โดย match แบบทนทานต่อรูปแบบจุด: `REPLACE(icd10, '.', '') LIKE 'Z34%'` หรือ `LIKE 'Z35%'`
   หมายเหตุ: บางโรงพยาบาลอาจกรองด้วยรหัสคลินิก ANC (`ovst.spclty`) แทนหรือเพิ่มเติม
   ให้ตรวจสอบรหัสคลินิกของตนเองจากตาราง `spclty` ก่อน [ปรับตามโรงพยาบาล]
2. **หาผล Hb ครั้งแรกของแต่ละคน**
   จาก `labs_head` join `lab_order` เอาเฉพาะรายการที่ `lab_items_code` อยู่ใน `@hb_codes`
   และผลเป็นตัวเลขจริง (กรองด้วย `REGEXP '^[0-9]+([.][0-9]+)?$'` ก่อน `CAST` เพราะ
   `lab_order_result` เป็น VARCHAR) แล้วเลือกวันที่สั่งตรวจแรกสุด (`MIN(order_date)`) ต่อ hn
   ด้วย `GROUP BY hn` แล้ว join กลับไปเอาค่า Hb ของวันนั้น
   ถ้าวันแรกมีผลหลายรายการ จะใช้ค่าต่ำสุดของวันนั้นเพื่อให้ผลคงที่ทุกครั้งที่รัน
3. **สรุปผล**
   นำ cohort จากขั้นที่ 1 มา LEFT JOIN กับผล Hb จากขั้นที่ 2
   คนที่ผล Hb ครั้งแรกต่ำกว่า `@hb_cutoff` ถูกนับเป็นตัวตั้ง
   คนที่ไม่มีผล Hb เลยไม่ถูกนับในตัวหาร แต่ถูกรายงานแยกไว้เป็นสัญญาณคุณภาพข้อมูล

ไฟล์ [hosxp.sql](hosxp.sql) มี 2 query:

- **Query 1** : ตารางสรุป จำนวนหญิงตั้งครรภ์ทั้งหมด, ตัวหาร, ตัวตั้ง, ร้อยละ, จำนวนที่ไม่มีผล Hb
- **Query 2** : รายละเอียดรายบุคคล (hn, วันที่ตรวจ Hb ครั้งแรก, ค่า Hb, ผลการคัดกรอง)
  ใช้ไล่ตรวจภายในเท่านั้น ห้ามแชร์ออกนอกโรงพยาบาล (ดู [docs/data-privacy.md](../../../docs/data-privacy.md))

## พารามิเตอร์ที่ต้องปรับ

| พารามิเตอร์ | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `@start_date` / `@end_date` | `2025-10-01` / `2026-09-30` | ช่วงวันที่ที่ต้องการ ค่าเริ่มต้นคือปีงบประมาณ 2569 (1 ต.ค. 2568 ถึง 30 ก.ย. 2569) |
| `@hb_codes` | `'0000'` | [ปรับตามโรงพยาบาล] รหัส `lab_items_code` ของรายการ Hb ในโรงพยาบาลของคุณ ใส่ได้หลายรหัสคั่นด้วยจุลภาค ไม่มีช่องว่าง เช่น `'123,456'` (query ใช้ `FIND_IN_SET` จึงรองรับหลายรหัสในตัวแปรเดียว) หารหัสด้วย helper query ที่อยู่ในไฟล์ hosxp.sql |
| `@hb_cutoff` | `11.0` | เกณฑ์ Hb (g/dL) ที่ถือว่าโลหิตจาง ดูหัวข้อนิยามด้านบน |

## วิธีใช้

1. รัน helper query เพื่อหารหัส lab ของ Hb ในโรงพยาบาลของคุณ
   (อยู่ในไฟล์ [hosxp.sql](hosxp.sql) หัวข้อ "Helper query" เปิด comment แล้วรันครั้งแรกครั้งเดียว)
   ระวัง: ห้ามใช้รหัสของ HbA1c ต้องเป็น Hb จาก CBC เท่านั้น ถ้าใส่รหัส HbA1c ผิด
   แทบทุกคนจะถูกนับเป็นโลหิตจางโดยไม่มี error เตือน
2. แก้ `@hb_codes` ให้ตรงกับรหัสที่พบ และแก้ `@start_date` / `@end_date` ตามช่วงที่ต้องการ
3. ถ้าโรงพยาบาลของคุณต้องการกรองด้วยคลินิก ANC เพิ่มเติม ให้เปิด comment เงื่อนไข `ovst.spclty` ใน query (มีทั้งใน Query 1 และ Query 2 ต้องแก้ให้เหมือนกันทั้งสองจุด)
4. รันทั้งไฟล์ด้วย DB user แบบอ่านอย่างเดียว และรันบน replica หรือนอกเวลาราชการถ้าฐานข้อมูลมีภาระสูง (ดู [docs/data-privacy.md](../../../docs/data-privacy.md))
5. อ่านผล Query 1 เทียบกับตัวเลขใน HDC ถ้าต่างกันมาก ให้ใช้ Query 2 ไล่ตรวจรายคน
6. Query 2 มีข้อมูลส่วนบุคคล ใช้ภายในโรงพยาบาลเท่านั้น ห้ามแชร์ออกนอกโรงพยาบาลทุกช่องทาง

## ข้อจำกัด

- นับเฉพาะหญิงตั้งครรภ์ที่มารับบริการและมีการลงรหัส Z34/Z35 ที่โรงพยาบาลนี้ ถ้าการลงรหัสไม่ครบ ตัวหารจะต่ำกว่าจริง
- ผล lab ที่ตรวจจากภายนอก หรือผลที่บันทึกเป็นข้อความ (เช่น "10.5 g/dL" หรือ "ปกติ") จะไม่ถูกนับ เพราะ query กรองเฉพาะค่าตัวเลขล้วน
- นิยาม HDC อย่างเป็นทางการอาจใช้เงื่อนไขครั้งแรกของการฝากครรภ์ ซึ่งต่างจาก query นี้เล็กน้อย (query นี้ใช้ผล Hb ครั้งแรกในช่วงวันที่ที่กำหนด)
- ควรเทียบผลกับ HDC ก่อนใช้รายงานทางการเสมอ
