# ร้อยละการคลอดก่อนกำหนด (Preterm Delivery Rate)

> query ในชุมชนนี้ใช้เพื่อตรวจสอบและเตรียมข้อมูลภายในโรงพยาบาลเท่านั้น ไม่ใช่ค่าทางการ
> ค่าทางการอ้างอิงจากระบบ HDC ของกระทรวง (https://hdcservice.moph.go.th)

## ชื่อตัวชี้วัดและความหมาย

ร้อยละของการคลอดก่อนกำหนด เทียบกับจำนวนการคลอดทั้งหมดในโรงพยาบาล ในช่วงปีงบประมาณที่กำหนด
ใช้ติดตามงานอนามัยแม่และเด็ก และเตรียมข้อมูลก่อนเทียบกับตัวเลขในระบบ HDC

## นิยามและแหล่งอ้างอิง

WHO นิยาม preterm birth คือทารกที่เกิดมีชีพก่อนอายุครรภ์ครบ 37 สัปดาห์ แบ่งกลุ่มย่อยดังนี้:

| กลุ่มย่อย | อายุครรภ์ |
|---|---|
| extremely preterm | น้อยกว่า 28 สัปดาห์ |
| very preterm | 28 ถึงก่อน 32 สัปดาห์ |
| moderate to late preterm | 32 ถึงก่อน 37 สัปดาห์ |

นิยามทางการของตัวชี้วัดฝั่งไทยอาจต่างจากนิยาม WHO ในรายละเอียด และเปลี่ยนได้ทุกปีงบประมาณ
ก่อนใช้รายงานทางการ ตรวจสอบนิยามและค่าเป้าหมายจาก template ตัวชี้วัดของปีงบประมาณปัจจุบันใน
HDC (https://hdcservice.moph.go.th) หรือ Health KPI กระทรวงสาธารณสุข (https://healthkpi.moph.go.th)

รหัส ICD-10 (WHO) ที่ใช้ใน query นี้:

- O80 ถึง O84 : รหัสการคลอด ใช้หาตัวหาร (จำนวนการคลอดทั้งหมด)
- O60.1 : preterm labour with preterm delivery ใช้หาตัวตั้ง (คลอดก่อนกำหนด)
- P07.2, P07.3 : รหัส prematurity ฝั่งทารกแรกเกิด ใช้ตรวจสอบไขว้ (query ทางเลือก)

## แนวคิดของ query

query นี้เลือกใช้รหัส ICD-10 จากตาราง `ipt` + `iptdiag` ซึ่งเป็นตารางแกนกลางที่มีใน HOSxP ทุกรุ่น:

1. **ตัวหาร** : admission (`an`) ที่มีรหัส O80-O84 และวันจำหน่าย (`dchdate`) อยู่ในช่วงเวลาที่กำหนด
   นับเป็นราย admission หมายถึงหนึ่งการคลอดต่อหนึ่งแม่ต่อหนึ่ง admission ครรภ์แฝดนับครั้งเดียว
2. **ตัวตั้ง** : admission ในตัวหารที่มีรหัส O60.1 ร่วมด้วย (ตรวจด้วย EXISTS subquery)
3. **ตรวจสอบไขว้ (ทางเลือก)** : นับ admission ของทารกแรกเกิดที่มีรหัส P07.2 หรือ P07.3 ในช่วงเวลาเดียวกัน
   query นี้นับ "ทารก" ไม่ใช่ "แม่" กรณีครรภ์แฝดตัวเลขจะต่างจากตัวตั้งของ query หลัก
   และขึ้นกับความครบถ้วนของการลงรหัสฝั่งทารก ใช้ดูว่าตัวเลขไปในทิศทางเดียวกันหรือไม่

การ match รหัสใช้ `REPLACE(icd10, '.', '')` เสมอ เพื่อรองรับทั้งโรงพยาบาลที่เก็บรหัสแบบมีจุดและไม่มีจุด

**ทำไมไม่ใช้อายุครรภ์ (GA) จากระบบห้องคลอด:**
โรงพยาบาลที่บันทึกอายุครรภ์ตอนคลอดในระบบห้องคลอดของ HOSxP สามารถคำนวณจากอายุครรภ์ได้ตรงกว่า ICD-10
แต่ชื่อตารางห้องคลอดต่างกันตามรุ่น (v3/XE) จึงไม่รวมไว้ใน query กลางนี้
หากโรงพยาบาลของท่านมีตารางดังกล่าว เชิญ[แบ่งปัน version ของท่านผ่าน issue "แบ่งปัน Query"](https://github.com/niratorn/MOPH_KPI-Report_SQL/issues/new?template=03-share-query.yml) ของ repo นี้

## พารามิเตอร์ที่ต้องปรับ

| พารามิเตอร์ | ค่าตัวอย่าง | คำอธิบาย |
|---|---|---|
| `@start_date` | `'2025-10-01'` | วันเริ่มปีงบประมาณ 2569 (1 ต.ค. 2568) |
| `@end_date` | `'2026-09-30'` | วันสิ้นสุดปีงบประมาณ 2569 (30 ก.ย. 2569) |
| filter `ward` (ทางเลือก) | comment ไว้ใน query | เปิดใช้ถ้าต้องการจำกัดเฉพาะ ward ห้องคลอด ปกติไม่จำเป็นเพราะกรองด้วยรหัส O80-O84 อยู่แล้ว |

## วิธีใช้

1. เปิดไฟล์ [hosxp.sql](hosxp.sql) แล้วแก้ `@start_date` และ `@end_date` ให้ตรงปีงบประมาณที่ต้องการ
2. รันด้วย DB user แบบ read-only และรันบน replica หรือนอกเวลาให้บริการ
   (ดู [docs/hosxp-basics.md](../../../docs/hosxp-basics.md))
3. รัน Query 1 เพื่อดูสรุป ตัวหาร ตัวตั้ง และร้อยละ
4. ใช้ Query 2 ไล่ตรวจราย admission ว่ารายใดถูกนับ รายใดพบ/ไม่พบรหัส O60.1
   ผลรายบุคคลมีข้อมูลส่วนบุคคล ห้ามแชร์ออกนอกโรงพยาบาล (ดู [docs/data-privacy.md](../../../docs/data-privacy.md))
5. รัน Query 3 เทียบกับตัวตั้งของ Query 1 และเทียบทั้งหมดกับสมุดทะเบียนห้องคลอด
   ถ้าตัวเลขห่างกันมาก มักชี้ว่าการลงรหัส O60.1 หรือ P07 ไม่ครบ
6. ก่อนใช้รายงานทางการ เทียบกับตัวเลขในระบบ HDC เสมอ

## ข้อจำกัด

- วิธีนี้พึ่งความครบถ้วนของการลงรหัส ICD-10 ทั้ง O80-O84 และ O60.1
  ถ้า coder ไม่ลง O60.1 ตัวตั้งจะต่ำกว่าความเป็นจริง
- นับเฉพาะการคลอดในโรงพยาบาลนี้ ไม่รวมการคลอดนอกโรงพยาบาลหรือที่หน่วยบริการอื่น
- ไม่แยก livebirth/stillbirth ด้วยรหัสชุดนี้ ขณะที่นิยาม WHO นับเฉพาะทารกเกิดมีชีพ
- Query 3 นับทารก ไม่ใช่แม่ และขึ้นกับความครบถ้วนของการลงรหัสฝั่งทารกแรกเกิด
- ควรเทียบกับสมุดทะเบียนห้องคลอดและระบบ HDC ก่อนใช้รายงานทางการ
