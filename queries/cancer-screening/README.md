# หมวดมะเร็งและการคัดกรอง (cancer-screening)

หมวดนี้ยังไม่มี query รอผู้แบ่งปันคนแรก

ตัวอย่างหัวข้อที่ชุมชนต้องการ: คัดกรองมะเร็งปากมดลูก, คัดกรองมะเร็งลำไส้ใหญ่, คัดกรองมะเร็งเต้านม

ถ้าโรงพยาบาลของคุณมี query เหล่านี้อยู่แล้ว [เปิด issue "แบ่งปัน Query"](https://github.com/niratorn/MOPH_KPI-Report_SQL/issues/new?template=03-share-query.yml) หรือส่ง PR ตามขั้นตอนใน [CONTRIBUTING.md](../../CONTRIBUTING.md)
